# TypeIcon

An icon library, downloadable icon-font system and website (target domain typeicon.net, not deployed).

- **Desktop keyword fonts.** OTF/TTF with real OpenType GSUB ligatures: install **TypeIcon Line**, type `home`
  in Figma or any app with ligatures, and get the icon. Switch the family to **TypeIcon Filled**,
  **TypeIcon Rounded** or **TypeIcon Thin** and the keyword stays the same (Thin has glyphs only for icons whose Thin
  differs from Line). Brand logos are in a separate **TypeIcon Brands** family.
- **Website.** Searchable catalog, icon detail pages (SVG/PNG download, copy SVG/HTML/CSS/React/Vue, glyph and
  codepoint), release downloads, a custom subset builder, collections, kits with private custom SVGs, docs and admin.
- **Developer delivery.** Web fonts + CSS (ligature and codepoint classes), SVG files and sprites, per-icon
  React and Vue components (tree-shakable), metadata JSON with TypeScript types, and a Figma plugin (source only).

## What is in the catalog

1. **TypeIcon Core**: original, hand-authored icons, each drawn once and exported in Filled, Line, Rounded and Thin (Thin only where it differs from Line). Core has base
   designs and **variants**: separately named concepts built from a base plus a designed badge in the
   bottom-right corner (`file-plus`, `user-off`, `bell-lock`). Codepoints `U+F0000 + n` with a BMP mirror at
   `U+E000 + n`.
2. **Brand logos** (`brand-github` …): imported from Simple Icons 16.33.0 into the single-style
   **TypeIcon Brands** family (codepoints from `U+100000`). The collection is CC0-1.0, but per-logo licenses
   are recorded, and logos under share-alike, non-commercial, GPL/AGPL, MPL or custom terms are quarantined.
   Brand logos are trademarks of their owners and **never** count toward the Core goal.

Tabler Icons, Phosphor Icons and Material Symbols were removed on 2026-09-30 (`docs/decisions.md`, entry 19).
Their codepoints are retired in `assets/registry/codepoints.json` and never reused.

## What exists today (honest numbers)

**The goal is 20,000 complete Core concepts** (base designs plus designed variants, each with Filled, Line and
Rounded; Thin does not change the count). **It is not met.** Current counts, the gap and base and variant totals (always reported separately)
are in `docs/catalog-audit.md`, generated by `typeicon-import audit`; the counting rules are in
`docs/policies/catalog-counts.md`. At the time of writing (2026-09-30): 80 Core base designs (4 of them
rotation-derived arrows/chevrons, not counted), 1,054 Core variants and 3,369 published brand logos, in release
0.2.0 (4 font families: Core Filled, Line, Rounded and Brands; this release predates the Thin style).

The software is built for a much larger catalog (search benchmarked at 150k designs, fonts at 50k glyphs; see
`docs/benchmarks.md`). The artwork is not there yet: it is a content-production programme, run through
`tools/core-authoring/AUTHORING.md`.

## Quick start (no Docker, no paid services)

Prerequisites: Node ≥ 22, pnpm 10, [uv](https://docs.astral.sh/uv/), PostgreSQL 17 binaries
(macOS: `brew install uv postgresql@17`).

```bash
bash scripts/setup.sh   # Python + Node deps, local Postgres, pinned sources, catalog, release, DB load, audit, test users
pnpm dev                # http://localhost:3107
pnpm worker             # background jobs: subset/kit builds, custom-icon checks, imports, releases
```

Docker alternative (written, not yet run here): `docker compose up --build`, then
`docker compose run --rm worker catalog-init`.

## Common commands

```bash
pnpm core:export          # regenerate Core SVGs (bases + variants) from tools/core-authoring
pnpm catalog:build        # pinned sources -> sanitized SVG + outlines + registry (idempotent; --dry-run available)
pnpm release:build        # compile + validate every family, package the release (version pinned in package.json)
pnpm catalog:load         # load catalog + release into Postgres and storage (transactional)
pnpm audit:catalog        # catalog-audit.json + docs/catalog-audit.md
pnpm packages:generate    # React/Vue/SVG/webfont/catalog packages from the release
pnpm test                 # Python (pytest) + web (Vitest unit + integration)
pnpm test:e2e             # Playwright (desktop + mobile, axe accessibility)
pnpm packages:verify      # typecheck, tree-shaking and SSR checks for the component packages
.venv/bin/typeicon-review-sheets 0.2.0   # SVG-vs-font review sheets (build/review/)
```

## Repository map

```text
apps/web/            Next.js site + API (catalog, detail, downloads, subset builder, kits, docs, admin)
apps/worker/         Python worker: Postgres job queue, subset/kit builds, custom SVG checks, imports, releases, outbox
tools/font-builder/  SVG sanitizer, SVG→outline converter, OpenType compiler, subsetter, validators, raster compare
tools/importers/     Source fetch/verify, adapters, catalog build, registry, release packager, DB loader, audit
tools/core-authoring/ Core authoring: DSL, badge modifiers, plan.json, quality gate (check.py), export
assets/core/         Canonical TypeIcon Core SVGs (filled/line/rounded/thin) + metadata
assets/sources/      Source manifest + license texts;   assets/registry/  codepoints (append-only), synonyms, overrides
packages/            @typeicon/{catalog,icons-svg,icons-webfont,react,vue} (local workspace names), figma-plugin
db/migrations/       SQL migrations;  docs/  architecture, policies, design spec, deployment, audit, benchmarks
```

Package names such as `@typeicon/react` are local workspace names. No npm scope, CDN domain or Figma Community
listing has been registered or published.
