# TypeIcon Core license (draft, owner decision required)

The TypeIcon Core artwork in `assets/core/` and the ASCII fallback letterforms compiled into
TypeIcon fonts are original works created for TypeIcon.

**The owner has not yet chosen public license terms.** Until they do, this repository treats Core
assets as:

- usable for local development and evaluation of TypeIcon itself;
- not yet cleared for public redistribution.

The catalog audit reports this as a license gap, and the release packager labels Core archives
`LicenseRef-TypeIcon-Core-Draft`.

Options for the owner to consider (not a recommendation of any third party's terms):

1. A permissive license for icons (e.g. MIT or CC BY 4.0) plus SIL OFL 1.1 for the compiled fonts.
2. A custom free license for downloads plus separate service terms for hosted kits and collaboration.

Whatever is chosen must remain compatible with the third-party Community Pack licenses, which are
preserved separately in `assets/sources/licenses/<pack>/` and are never relicensed by TypeIcon.
