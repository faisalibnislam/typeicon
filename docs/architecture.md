# TypeIcon architecture

Status: living document. Last updated 2026-09-30.

## Goals that shape the architecture

1. **Real desktop keyword fonts.** OTF/TTF files with OpenType `liga`/`rlig` GSUB ligatures so typing `home` in Figma renders the icon. This is compiled in Python with fontTools and verified with HarfBuzz (uharfbuzz) and OpenType Sanitizer. No JavaScript substitution is involved.
2. **Honest catalog.** Every count shown anywhere is computed from published database rows or the audit. TypeIcon Core (unified designs drawn once and exported in every style; base designs and badge variants reported separately) is counted separately from brand logos, which never count toward the Core goal.
3. **Scale-ready, content-limited.** The goal is 20,000 complete Core concepts (Filled, Line and Rounded each; Thin is extra and not counted; goal not met), and the system is benchmarked well beyond that (50,000 glyphs per font, 150k designs in search), but the real catalog is whatever the audit reports.

## Components

```text
apps/web/              Next.js App Router site (catalog, detail, downloads, docs, kits, admin, API routes)
apps/worker/           Python job worker (Postgres queue: SKIP LOCKED): kit builds, release packaging
packages/catalog/      Generated catalog snapshot + TypeScript types (metadata JSON, glyph map)
packages/icons-svg/    Generated sanitized SVGs + sprites
packages/icons-react/  Generated per-icon React components (no default barrel of the catalog)
packages/icons-vue/    Generated per-icon Vue components
packages/icons-webfont/Generated WOFF2/WOFF + CSS
tools/importers/       Python: pinned source fetch, SVG sanitize/normalize, catalog DB load, audit
tools/font-builder/    Python: SVG→outline conversion, OpenType compiler, subsetter, validators
tools/core-authoring/  Python design tooling that produced the canonical Core SVGs (see docs/design)
assets/core/           Canonical TypeIcon Core SVG sources (committed, editable)
assets/sources/        Source manifest + pinned lock data (tarballs cached in .cache/, not committed)
db/migrations/         SQL migrations (generated by drizzle-kit from apps/web schema, applied by runner)
docs/                  Policies, design spec, guides, compatibility matrix, deployment
```

## Data flow

```text
pinned upstream tarball (sha512 integrity)          assets/core/svg/{filled,line,rounded,thin}/*.svg
        │                                                     │
        ▼                                                     ▼
  tools/importers: fetch → verify checksum → extract immutable originals (.cache/sources/<pack>/<ver>/)
        │
        ▼
  sanitize (safe XML, allow-list)  →  normalized display SVG (strokes kept, currentColor)
        │
        ▼
  picosvg + skia-pathops  →  font-ready outline (strokes expanded, transforms flattened,
                             overlaps removed, holes preserved, y-axis inverted at compile time)
        │
        ▼
  catalog build (build/catalog/*.json) ──► PostgreSQL (transactional import, unique constraints)
        │                                        │
        ▼                                        ▼
  font-builder: OTF(CFF) + TTF(glyf) + WOFF2 + WOFF,   web app reads published rows only
  GSUB liga/rlig, cmap 4+12, name/OS2/post,             search: tsvector + pg_trgm
  validators: OTS, HarfBuzz shaping, raster compare
        │
        ▼
  release packager → dist/releases/<version>/ (zips, checksums) → object storage (local FS or S3/R2)
```

## Runtime services

| Service | Local (no paid credentials) | Production |
|---|---|---|
| PostgreSQL 17 | `scripts/dev-db.sh` (Homebrew binaries, data in `.data/pg`) or Docker Compose | Managed Postgres (Neon/Supabase/RDS) |
| Object storage | `STORAGE_DRIVER=fs` (`.data/storage`) or MinIO in Docker Compose | Cloudflare R2 / S3 behind CDN |
| Worker | `pnpm worker` (Python, polls `jobs` table) | Long-running container (Fly.io, Railway, ECS, a VM), **not** serverless |
| Auth | Better Auth, email + password, sessions in Postgres | Same; add OAuth providers when configured |

Font builds never run inside a web request. The web app inserts a `jobs` row; the worker claims it with
`SELECT … FOR UPDATE SKIP LOCKED`, runs with CPU/memory/time limits, writes artifacts to storage,
and records status transitions (`queued → running → succeeded|failed`, retries with backoff).

## Key decisions (see docs/decisions.md for the log)

- **Separate families per style** (`TypeIcon Filled`, `TypeIcon Line`, `TypeIcon Rounded`, `TypeIcon Thin`), each
  Regular/400. Style is not a weight.
- **Codepoints are integers** in the DB; Core uses Plane 15 PUA with a permanent BMP PUA mirror for the
  first 6,400 Core concepts (see docs/policies/naming-and-codepoints.md).
- **Glyph IDs are never public identifiers.** Public IDs are variant UUIDs and canonical slugs.
- **Brand logos** (Simple Icons) keep their source identity, `brand-` names (`brand-github`), a single `brand`
  style and their own family (`TypeIcon Brands`, Plane 16 PUA). They never count toward the Core target (Filled, Line, Rounded). The former Tabler, Phosphor and Material Symbols packs were removed on 2026-09-30.
- **Single ligature lookup** with multiple subtables (split automatically on overflow, promoted to
  Extension lookups) so that leftmost-longest matching holds across the whole name set.
